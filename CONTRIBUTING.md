# Contributing

Thank you for contributing to `NTNX-vm-write-stats-collector`.

## Before opening a pull request

* Do not include passwords, tokens, private keys, customer names, hostnames, IP addresses, raw API responses, or generated output.
* Run `./tests/validate.sh`.
* Review `git diff` and `git status --ignored` before pushing.
* Update both `README.md` and `README.de.md` when user-facing behavior changes.
* Keep changes focused and document any change to calculations or metric interpretation.

## Pull requests

Describe:

* What changed.
* Why the change is needed.
* How it was tested.
* Whether output files, formulas, API versions, or security behavior changed.

This repository currently has no license. Contributions should be discussed before submitting substantial code changes.
